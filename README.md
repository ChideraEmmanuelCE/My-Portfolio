# Chidera Emmanuel — Portfolio Rebuild

This is a lightweight static portfolio rebuild containing only the three selected projects:

1. Pocket POS — https://pocket-pos.netlify.app
2. Nova Digital — https://my-nova-digital.netlify.app
3. Quick Bill Split — https://quick-bill-split.netlify.app

## Run locally

Open `index.html` directly in your browser, or use VS Code + Live Server.

## Customize

Most of the portfolio is contained in `index.html`.

Change:
- colors in the `:root` CSS variables
- hero text
- project descriptions
- project links
- About section
- contact links
- typography and spacing

## Deploy to Netlify

This is a plain static site. Keep `index.html` in the root of the folder.

You can deploy it by dragging the entire folder into Netlify's deploy/drop area, or connect the folder/repository to Netlify for continuous deployment.
